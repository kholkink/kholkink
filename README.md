### Hi, I'm NoJokes 👋

I build ML systems that have to work under hard constraints: 9-hour offline Kaggle notebooks, 3-bit quantized LLMs,
sandboxed agents with no internet. Every project here ends with an honest write-up of what worked and what didn't.

- 🔬 **Now:** molecule identification from MS/MS spectra (Kaggle CASMI26) and a Gemma 4 coding agent
- 🧠 **Interests:** LLM agents, model compression, medical imaging, retrieval and ranking, procedural generation
- 📊 **Kaggle:** [kirillkholkin](https://www.kaggle.com/kirillkholkin)

## Featured projects

| Project | What it is | Stack |
|---|---|---|
| [**rsna-knee-mri**](https://github.com/kholkink/rsna-knee-mri) | Kaggle RSNA Knee Abnormality Detection: LLM-extracted soft labels from multilingual MRI reports, 2.5D study-level models, offline DICOM pipeline. Best own model 0.933 public LB. | PyTorch · timm · pydicom |
| [**lcd-ru**](https://github.com/kholkink/lcd-ru) | Research on language-conditional low-rank corrections for 3-bit GPTQ LLMs in Russian. Replicates LCD and shows why MMLU accuracy recovers about half as much as perplexity. | PyTorch · Transformers · llm-compressor |
| [**gd-levelgen**](https://github.com/kholkink/gd-levelgen) | A 335M-parameter transformer that writes Geometry Dash levels token by token, with a physics simulator (Python + C++) and a Geode mod to play the results in-game. | PyTorch · C++ · Geode |
| [**Kontur**](https://github.com/kholkink/Kontur) | Autonomous cybersecurity agent for offline runtimes: deterministic audit / code-fix / forensics / CTF playbooks first, local LLM second. Standard library only. | Python |
| [**tax-corpus**](https://github.com/kholkink/tax-corpus) | Structured parser and agent toolkit for the Russian Tax Code: canonical unit IDs, reference resolution, hybrid search, citation checking. | Python · PostgreSQL · RAG |
| [**poe2crafthelper**](https://github.com/kholkink/poe2crafthelper) | Path of Exile 2 crafting optimizer: an MDP / stochastic-shortest-path solver with Monte-Carlo validation and an LLM assistant on top. | Python · MDP |
